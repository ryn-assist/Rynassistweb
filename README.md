# Ryn Assist Web

Website toko digital untuk **rynassist.my.id**.

## Halaman
- Beranda
- Payment
- Daftar Harga
- Kalkulator Refund
- Admin prototype

Navigasi memakai hash route agar aman dijalankan di GitHub Pages.

## Data
Versi prototype menyimpan data Payment dan Daftar Harga di localStorage. Tahap berikutnya dapat dipindahkan ke Supabase Auth + PostgreSQL agar data admin tersimpan online dan dapat dikelola dari HP.

## Deploy
Repository ini disiapkan untuk GitHub Pages melalui GitHub Actions.

Catatan: data harga/payment di dalam project masih berupa placeholder dan perlu diganti dengan data toko sebenarnya.
